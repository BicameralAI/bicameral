# Legacy decision records (frozen)

These records came in with this component's import. They are kept as history and are not authoritative.

The folder is frozen. Files here must match `governance/legacy-decisions.json`, and the structure check rejects any addition, edit or removal.

New decisions go in [`docs/architecture/records/`](../../../../docs/architecture/records/). When a new record depends on, supersedes or revives one of these, rewrite that record there first and check its status. See ARCH-0001.
