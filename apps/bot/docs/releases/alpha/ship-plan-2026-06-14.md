# Alpha Ship Plan — Download Link Live Sunday, June 14

Owner: Jin (release captain). This file is the only planning doc for the alpha. If it's not in here, it doesn't happen before Sunday.

## Goal

An external engineering team goes from download link → running workspace → first reviewed decision in under 15 minutes, unassisted. That is the whole release.

## Cut line

**Ships (already supported in dispatch):**
`ingest.submit_local`, `history.list`, `search.query`, `review.accept_candidate`, `review.reject_candidate`, `review.approve_signoff`, `review.reject_signoff`, `binding.create`, `binding.inspect` — plus `bicameral init / doctor / dashboard / service`, the dashboard SetupWizard (create-workspace path only), and the V1 golden path.

**Does not ship (must fail with a clear typed error, never a crash):**
`preflight.run`, `review.resolve_compliance`, `tracking.*`, token telemetry, InviteBundle "join workspace", multi-team graph scope.

Rule: nothing crosses this line before Sunday. After the Friday gate, bugfixes only.

## Beta kit (what Lovis sends to leads)

1. **One-pager** framed on the pain point — *context fragmentation after AI adoption* — not features. No "decision ledger" jargon in the hook; that's the explanation, not the opener.
2. Download link + QUICKSTART.
3. Calendar link for a standing weekly call. The ask in every conversation: "what would it take for you to run this for two weeks" — capture their answer verbatim; those answers are the backlog.

Target profile: teams small enough to commit to weekly calls (or a 5–6 person sub-team inside a larger org, e.g. Jacob's). Decision-maker ≤ 1 hop away.

## Validation scorecard (per beta team, reviewed weekly)

The product is invisible when it works — so we measure proxies, not vibes:

| Metric | How (interim, pre-telemetry) |
|---|---|
| Token spend delta | Ask teams for their agent bill (Devin/Claude) before/after; our own internal $700/mo Devin spend is case study #1 |
| Drift catches | Count of issues bicameral flagged that the team confirms they'd have missed |
| Activation | Completed golden path; weekly active reviewers |
| Setup friction | Time-to-first-decision; number of support pings |

Token telemetry (`docs/specs/token-telemetry-spend-events.md`) is spec-complete, zero code. It is **post-alpha priority #1** (owner TBD) because it converts the scorecard from anecdotes to invoices.
