# Code of Conduct

Bicameral adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies to everyone participating in this project's spaces.

The Covenant's enforcement section refers to a reporting contact. **A dedicated reporting channel has not yet been published.** Until it is, raise conduct concerns privately with a maintainer listed in [MAINTAINERS.md](MAINTAINERS.md). A dedicated channel and enforcement process will be documented here before the project accepts public contributions.
