# `docs/assets/branding/`

Bicameral brand assets used by repository documentation. They are not redesigns: each one reproduces the brand standards maintained in `BicameralAI/bicameral-site` (`visual-plans/brand-standards.html`, section 02 "Logo").

| File | Form | Provenance |
| --- | --- | --- |
| `bicameral-tile.svg` | Tile: white mark on an ink (`#18181b`) square | Mark geometry copied verbatim from the brand standards (`circle r=40, stroke-width=13, stroke-dasharray="107.6 18.06", rotate(-32)`), inset to 62% of the tile as specified there |
| `bicameral-tile-1024.png` | Tile, 1024×1024 raster | Byte-identical copy of `site/static/logo.png` from `BicameralAI/bicameral-site` at `e3d39b31c75def93da6d2af0811664462dad5b39` (SHA-256 `2e96815bd1180b579f118b23a44b5784ec53a00209033dbba4513ca88b044f76`) |
| `bicameral-lockup-light.svg` | Primary lockup (tile + `bicameral` wordmark), ink wordmark for light backgrounds | Tile as above; wordmark in the specified monospace, weight 700, −0.02em tracking, with the standards' tile-to-type proportions |
| `bicameral-lockup-dark.svg` | Primary lockup, white wordmark for dark backgrounds | As above |

Usage rules from the brand standards:

- The tile is the universal form and the only form allowed on colored or photographic backgrounds.
- The mark is monochrome only, with fixed geometry: never cyan, purple or gradients; keep the diagonal cut and transparent counter.
- The lockup's use rule (L-02) is marked *exploratory* in the brand standards. If that changes, these files follow the standards, not the other way round.

The SVG wordmark is set as text with a monospace font stack, so its letterforms depend on fonts available to the viewer. Brand changes are made in the brand standards first and copied here.
